# 1. Introduction a Alchemix

Ce parcours lit le protocole depuis ses contrats, ses interfaces et son README. Il identifie le probleme traite, les acteurs et les flux de valeur sans reduire la DApp a son interface. La premiere carte mentale repose sur les composants nommes dans le depot. Le depot source expose notamment Transmuter, alAssets, yield strategies, debt repayment, credit delegation, liquidation.
